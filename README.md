# 治安管理处罚法学习助手（Android 工程）

一个用于学习《中华人民共和国治安管理处罚法》（2025 年 6 月 27 日修订，2026 年 1 月 1 日施行，共 6 章 144 条）的安卓 App 源码工程，包含**法条速查、闯关刷题、情景判案、错题库**四大功能，全部数据内置，离线可用。

## 一、怎么装到手机上

> 说明：本仓库只含**源码**，需要先编译才能安装。仓库内已附带 GitHub Actions 配置，可云端编译直接下载 APK（见方式 C）。

### 方式 A：Android Studio（最省事）
1. 安装 [Android Studio](https://developer.android.com/studio)（Hedgehog 及以上版本），首次启动时确保能联网下载 Gradle 依赖。
2. 打开 Android Studio → `File → Open` → 选择本文件夹 **`ZhianApp`**（注意选到带 `settings.gradle` 的这一级）。
3. 等待 Gradle Sync 完成（首次约需几分钟）。
4. 手机开启「开发者选项 → USB 调试」并用数据线连接，或直接使用模拟器。
5. 点击工具栏 ▶ **Run**，App 会安装到设备上；安装后桌面图标为「治安法学习助手」。

### 方式 B：命令行打包 APK
```bash
cd ZhianApp
./gradlew assembleDebug        # Windows 用 gradlew.bat assembleDebug
```
生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，传到手机点击安装即可（需允许「未知来源应用」安装）。

> 环境要求：JDK 17、Android SDK 34。
> 若提示 `gradle-wrapper.jar` 缺失，用 Android Studio 打开一次会自动补齐；或执行 `gradle wrapper --gradle-version 8.2` 生成。

### 方式 C：用 GitHub Actions 云端编译（不用装 Android Studio）
1. 把整个 `ZhianApp` 文件夹内容传到一个 GitHub 仓库（保持 `settings.gradle` 在仓库根目录）。
2. 进入仓库页面 → **Actions** → 左侧选 `Build APK` → 点 **Run workflow**。
3. 约 3–5 分钟后，工作流跑完，在 **Artifacts** 里下载 `zhian-app-debug`，解压即得 APK，传到手机安装。

### 方式 D：不装 APK，直接用网页版（立即可用，可装桌面）
同目录下的 `治安管理处罚法学习助手.html` 是单文件网页版，功能与 App 完全一致：
- 手机浏览器打开该文件 → 安卓 Chrome/Edge 右上角「⋮」→「添加到主屏幕 / 安装应用」
- iPhone 用 Safari 打开 → 底部「分享」→「添加到主屏幕」
装好后桌面出现图标，点开全屏运行，**完全离线可用**，无需网络。

## 二、三个功能模块

| 模块 | 能做什么 |
| --- | --- |
| 法条速查 | 全部 144 条内置；关键词搜索（支持直接输入条号）、按章节筛选、条文收藏、上一条/下一条连续阅读；从详情返回列表会自动回到刚才读到的那一条并高亮 |
| 闯关刷题 | 106 道四选一题目，每关 10 题，答完即时判分并给出解析与条文出处；正确率 ≥60% 解锁下一关；答错自动进错题本，支持「只练错题」 |
| 情景判案 | 31 个贴近生活的真实场景（高空抛物、遛狗不拴绳、噪音扰民、校园欺凌、无人机黑飞等），先判断处罚结论，再看解析并可一键跳转对应条文 |
| 错题库 | 练习题与情景案例的错题统一收进来，按错误次数排序；支持「全部 / 仅重点 / 仅练习题 / 仅情景案例」筛选，可单条或整轮重练 |

**错题库规则**

- 答错一次即进入错题库，并记录累计错误次数。
- 答对一次，待清偿次数减 1；减到 0 才移出错题库（错 4 次就要连答对 4 次）。
- 累计错误次数 **超过 3 次**（即第 4 次起）自动标记 **★ 重点**，排序时置顶，便于集中突破。

## 三、目录结构

```
ZhianApp/
├── app/src/main/
│   ├── assets/          law.json（144条全文）、quiz.json（题库）、cases.json（情景案例）
│   ├── java/com/yuanbao/zhian/
│   │   ├── MainActivity.kt        主界面（底部三栏 + 左右滑动容器）
│   │   ├── LawDetailActivity.kt   条文详情（收藏、上一条/下一条）
│   │   ├── data/                  数据模型、JSON 读取、学习进度存储
│   │   └── ui/                    法条 / 刷题 / 情景三个页面
│   └── res/                       布局、菜单、颜色、图标
├── build.gradle / settings.gradle / gradle.properties
```

学习进度（收藏、错题及错误次数、已解锁关卡、各关最高分）保存在手机本地 SharedPreferences 中，卸载 App 会清空。

## 四、数据与免责说明

- 法条正文依据 2025 年 6 月 27 日第十四届全国人大常委会第十六次会议修订通过、自 2026 年 1 月 1 日起施行的版本整理，条文编号与内容与官方公布文本一致。
- 题库与情景案例为依据上述条文编写的**学习辅助材料**，用于帮助理解记忆，不是执法依据，也不构成法律意见。
- 涉及具体案件时，请以全国人大网、中国政府网公布的正式文本及有权机关的解释为准。
